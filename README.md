# Проверки еНот & ЕИС

Версия 0.2.1

Программа отправляет запросы по участникам сделки через еНот и клиент ЕИС.
Можно сохранить сделку и позже повторить проверки с теми же данными или выполнить разовую проверку без сохранения.

## Что изменилось

Добавлены запросы в регистр населения и проверки дееспособности в клиенте ЕИС.
Все участники проходят один этап, затем программа переходит к следующему.
После успешного запуска выводится короткое сообщение. При ошибке указаны участник, этап и причина остановки.
Обновлены название приложения и инструкция по сборке.

## Как пользоваться

Откройте еНот и клиент ЕИС, закройте их диалоговые окна.
Введите участников, выберите нотариуса или ВРИО, вставьте ключ подписи и подтвердите его кнопкой ОК.
СНИЛС необязателен. Если его нет, проверка дееспособности этого участника пропускается.

Порядок работы:

1. Запросы в ЗАГС по всем участникам.
2. Запросы по брачным договорам по всем участникам и одно нажатие F5 в еНоте.
3. Запросы в регистр населения по всем участникам.
4. Запросы о дееспособности по участникам со СНИЛС.

Во время проверки не пользуйтесь мышью и клавиатурой. Для остановки нажмите F8.
Остановка не отменяет уже отправленные запросы. Перед повторным запуском после ошибки проверьте журналы обоих приложений.
Перед первым использованием на рабочем ПК нужно проверить доступность элементов настоящего клиента ЕИС через Win32/UIA.

Сделки хранятся локально. Путь можно посмотреть кнопкой «Папка данных».
Само приложение не отправляет данные в сторонние сервисы. Штатные запросы выполняют еНот и клиент ЕИС.

## Сборка

Нужны Python 3.11 x64 и Inno Setup 6. Из папки проекта выполните:

```powershell
py -3.11 -m venv C:\EnotBuildEnv
C:\EnotBuildEnv\Scripts\python.exe -m pip install -r requirements.lock.txt
C:\EnotBuildEnv\Scripts\python.exe build.py --output-root C:\EnotBuildOutput_0.2.1 --iscc "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

Папка для результатов должна быть новой или пустой.
Установщик появится в `C:\EnotBuildOutput_0.2.1\release\Setup_EnotChecks_0.2.1.exe`.
Для запуска без установки нужна вся папка `dist\EnotChecks`, включая `_internal`.
Пользователю готового приложения Python отдельно устанавливать не нужно.

Лицензии сторонних компонентов находятся в `licenses`.
