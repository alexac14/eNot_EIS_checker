# Проверки еНот 0.1.3

Локальное приложение для Windows 10/11 x64: проверки ЗАГС и брачных договоров,
несколько участников, сохранение сделок и повторные запуски.
Порядок: ЗАГС по всем участникам → брачные договоры по всем → одно финальное F5.

## Исправления

- Восстановлены ограничения ввода; ошибки показываются после выхода из поля.
- Клик по фону снимает фокус. Диалоги открываются сразу по центру, без зависаний.
- Плашка прогресса не перекрывает рабочие элементы и диалоги подписания.
- Добавлено подтверждение Enter после выбора сертификата для каждой подписи.

Данные сохраняются локально. Настоящий еНот выполняет свой штатный обмен с ЕИС.
Обработка дополнительного окна подписи временная, до уточнения на рабочем ПК.
Совместимость с настоящим еНотом ещё предстоит проверить. Инструкция — в `docs`.

## Сборка

Нужны Python 3.11 x64 и Inno Setup 6. Создайте окружение вне папки исходников
и установите зависимости из `requirements.lock.txt`:

```powershell
python -m venv C:\EnotBuildEnv
C:\EnotBuildEnv\Scripts\python.exe -m pip install -r requirements.lock.txt
C:\EnotBuildEnv\Scripts\python.exe build.py --output-root C:\EnotBuildOutput --iscc "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

Каталог результатов должен быть новым или пустым.
Программа: `C:\EnotBuildOutput\dist\EnotChecks\EnotChecks.exe`.
Для переноса без установки нужна вся папка `EnotChecks`, включая `_internal`.
Установщик: `C:\EnotBuildOutput\release\Setup_EnotChecks_0.1.3.exe`.
Пользователю готового приложения Python отдельно не требуется.

Изменения сначала проверяются в «Рабочем билде». Перенос в «Для GitHub» —
только с отдельного разрешения владельца. Публикацию на GitHub выполняет владелец.
