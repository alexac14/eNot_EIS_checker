# Проверки еНот — рабочий выпуск 0.1.2

Исходники рабочего приложения для Windows 10/11 x64. Основа — версия 0.1.2.
Исправление от 30.10.2026: новые запросы по дате находятся сверху таблицы.
ЗАГС: проверяются две новые верхние строки; брачные договоры: одна верхняя.
Перед подписанием сверяются ФИО, дата рождения, тип запроса и состояние.
Старая история сохраняется, при несовпадении программа останавливается.

Порядок: ЗАГС по всем участникам → брачные договоры по всем → одно финальное F5.
Ожидания динамические, предел — 45 секунд на переход. Сделки хранятся локально.
Инструкция для сотрудника и состав сторонних компонентов находятся в `docs`.
На настоящем еНот совместимость ещё предстоит проверить на рабочем компьютере.

## Разработка и выпуск

Изменения сначала выполняются и проверяются в соседней папке «Рабочий билд».
В рабочий выпуск переносятся только проверенные изменения по команде владельца.
Эта папка содержит исходники и документацию. Заполнения, базы сделок, отчёты
прогонов и дополнительные приложения сюда не переносятся.

## Сборка

Для сборки нужен Windows, Python 3.11 x64 и Inno Setup 6. Установленному
пользователю Python и компиляторы не требуются. Зависимости фиксированы
в `requirements.lock.txt`, модели локального OCR включены в исходники.

Создайте виртуальное окружение вне этой папки, установите зависимости:

```powershell
python -m venv C:\EnotBuildEnv
C:\EnotBuildEnv\Scripts\python.exe -m pip install -r requirements.lock.txt
```

Из этой папки запустите сборку, указав новый пустой каталог результатов
и фактический путь к компилятору Inno Setup:

```powershell
C:\EnotBuildEnv\Scripts\python.exe build.py --output-root C:\EnotBuildOutput --iscc "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

Готовый установщик: `C:\EnotBuildOutput\release\Setup_EnotChecks_0.1.2.exe`.
Существующие результаты сборки скрипт не удаляет и не перезаписывает.
